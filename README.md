# secretary.ai

**Live app:** https://an-app-that-helps-qtahu.omgs.page

Made with [omg.dev](https://make.omg.dev).

## Run it on your computer

1. Install [Bun](https://bun.sh).
2. In this folder, run `bun install`.
3. Run `bun run dev` and open the address it prints.

Run `bun run build` to make a production build.

## Change it

Open the app on [make.omg.dev](https://make.omg.dev) and describe the change. Then choose **GitHub** in the app menu and push the new version.
